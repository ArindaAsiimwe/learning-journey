# My Git, GitHub and Cybersecurity Learning

This week, I learned several important things about **Git and GitHub**. I learned that **Git** is a version control tool, while **GitHub** is an online platform used to host and collaborate on Git repositories.

I learned how **branches** are used to create a separate working area for making changes. I also learned about **merging**, which allows changes from one branch to be combined with another branch.

I learned about **Pull Requests (PRs)** and how they are used to request that changes from one branch be reviewed and merged into another branch. This is especially useful when working with a team because changes can be checked before they are added to the main project.

I also learned about the **GitHub CLI**, which allows me to perform GitHub tasks from the command line. I am still practising the different commands and learning how to use them confidently.
