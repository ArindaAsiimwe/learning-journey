# My Learning and Career Track

## Git and GitHub

This week, I learned how Git and GitHub are used in software development and teamwork.

I learned that **Git** and **GitHub** are not the same thing. Git is used for version control, while GitHub provides an online platform where Git repositories can be hosted and shared.

One of the things I found useful was learning about **branches**. A branch gives me a separate place to make changes without changing the main project immediately.

I also learned about **merging**, which is used to bring changes from one branch into another branch.

## Pull Requests

I learned about **Pull Requests (PRs)** and how they can be used when working with other developers.

A Pull Request allows someone to suggest changes to a project. The changes can then be reviewed before they are merged into the main branch.

This showed me how GitHub can make teamwork easier and help developers review each other's work.

## Using GitHub CLI

Another thing I learned this week was the **GitHub CLI**.

The GitHub CLI makes it possible to interact with GitHub from the command line. I am still learning the different commands and practising how to use them.
